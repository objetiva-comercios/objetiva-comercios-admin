# Quick Task 260318-2l2: Escala UI 90% Global Configurable — Summary

**One-liner:** font-size 90% aplicado al elemento html via localStorage con controles de preset en Settings > Apariencia.

## What Was Built

Hook `useUiScale` y componente `UiScaleInit` para escalar toda la UI de forma global mediante `document.documentElement.style.fontSize`. El componente se monta en el root layout y aplica la escala al inicio sin parpadeo. Los controles en Settings > Apariencia permiten elegir entre 80%, 85%, 90%, 95% y 100%, con feedback visual inmediato y persistencia entre sesiones.

## Decisions Made

- **UiScaleInit separado del hook:** El componente aplica la escala leyendo directamente localStorage sin usar el hook, para no introducir estado en el root layout (server component boundary).
- **Rango 80-100:** Suficiente para ajustar densidad sin hacer la UI inutilizable.
