Modificar los componentes internos de articulo-sheet.tsx para crear jerarquia visual clara. Todos los cambios son solo de clases CSS Tailwind, no de estructura JSX ni logica.

**SectionHeader** — Cambiar de:

```
text-xs font-medium text-muted-foreground uppercase tracking-wide
```

A:

```
text-sm font-semibold text-foreground border-l-2 border-primary pl-2
```

Esto crea un ancla visual con borde izquierdo de acento + texto mas prominente (text-foreground en vez de muted, font-semibold en vez de medium, text-sm en vez de text-xs). Quitar uppercase y tracking-wide para que se lea mas natural.

**FieldRow** — Cambiar label de:

```
text-sm text-muted-foreground shrink-0
```

A:

```
text-sm font-medium text-muted-foreground shrink-0
```

Solo agregar font-medium a la label para diferenciarla del valor.

**StatCard** — Agregar borde izquierdo de acento. Cambiar contenedor de:

```
flex-1 bg-muted rounded-sm p-3
```

A:

```
flex-1 bg-muted rounded-sm p-3 border-l-2 border-primary/30
```

Esto agrega un sutil borde izquierdo en color primary con 30% opacidad.

**CollapsibleSection trigger** — Cambiar de:

```
flex items-center gap-2 text-sm font-medium hover:underline [&[data-state=open]>svg]:rotate-90
```

A:

```
flex items-center gap-2 text-sm font-semibold text-foreground hover:text-primary transition-colors [&[data-state=open]>svg]:rotate-90
```

Quitar hover:underline (se siente legacy), usar hover:text-primary + transition-colors (mas moderno). Usar font-semibold y text-foreground para mayor prominencia.

**Tabla de stock — thead** — Agregar bg-muted a la fila de headers. Cambiar:

```html
<tr></tr>
```

A:

```html
<tr className="bg-muted"></tr>
```

Esto ancla visualmente los headers de la tabla.

**Secciones contenedoras** — Envolver el contenido de cada seccion principal (Propiedades, Stock) en un contenedor con fondo sutil. Cada div que actualmente solo tiene SectionHeader + contenido, agregar al div contenedor:

```
bg-card/50 rounded-sm border p-3
```

Aplicar esto a:

1. El div de Propiedades (linea ~269): cambiar `<div>` a `<div className="bg-card/50 rounded-sm border p-3">`
2. El div de Stock por Deposito (linea ~303): cambiar `<div>` a `<div className="bg-card/50 rounded-sm border p-3">`
