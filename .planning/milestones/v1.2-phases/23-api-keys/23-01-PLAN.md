       - `keyHash: varchar('key_hash', { length: 64 }).notNull().unique()`
       - `prefix: varchar('prefix', { length: 20 }).notNull()` — display only, NOT unique
       - `createdAt: timestamp('created_at').notNull().defaultNow()`
       - `lastUsedAt: timestamp('last_used_at')`
       - `revokedAt: timestamp('revoked_at')`
       - Indexes: `uniqueIndex('api_keys_key_hash_idx').on(table.keyHash)`, `index('api_keys_revoked_at_idx').on(table.revokedAt)`
       - Export `ApiKey` and `NewApiKey` inferred types.

    2. **DTO** — Create `create-api-key.dto.ts` with class-validator: `name: string` (IsString, IsNotEmpty, MaxLength(100)).

    3. **Service** — Create `api-keys.service.ts` injecting `DrizzleService`. Methods:
       - `create(name: string)`: Generate key with `crypto.randomBytes(32).toString('hex')`, build `fullKey = 'obj_sk_' + random.substring(0, 33)` (~40 chars total), `prefix = 'obj_sk_...' + random.substring(29, 33)`, hash with `createHash('sha256').update(fullKey).digest('hex')`. Insert into DB. Return `{ key: created row, fullKey }`. The fullKey is NEVER stored.
       - `findAll()`: Select where `revokedAt IS NULL`, order by `createdAt desc`.
       - `revoke(id: number)`: Update `revokedAt = new Date()` where `id = id AND revokedAt IS NULL`.
       - `findByToken(token: string)`: Hash token with SHA-256, select where `keyHash = hash AND revokedAt IS NULL`, limit 1. Return row or null.
       - `updateLastUsed(id: number)`: Update `lastUsedAt = new Date()` where id. This is called fire-and-forget — catch and log errors, never throw.

    4. **Controller** — Create `api-keys.controller.ts` with prefix `'api-keys'`:
       - `POST /` — `@UseGuards(RolesGuard) @Roles('admin')`. Accept `CreateApiKeyDto`. Call `service.create(dto.name)`. Return `{ id, name, prefix, createdAt, fullKey }` (201). **Critical:** Add a custom decorator or check in the controller that rejects API key auth for these routes — if `request.user.userId.startsWith('apikey:')`, throw ForbiddenException('Las API keys no pueden gestionar API keys'). This prevents key escalation.
       - `GET /` — `@UseGuards(RolesGuard) @Roles('admin')`. Call `service.findAll()`. Return array of `{ id, name, prefix, createdAt, lastUsedAt }`.
       - `DELETE /:id` — `@UseGuards(RolesGuard) @Roles('admin')`. Parse id as number. Call `service.revoke(id)`. Return 204.
       - All three endpoints must check `userId.startsWith('apikey:')` and reject with 403 if true.
