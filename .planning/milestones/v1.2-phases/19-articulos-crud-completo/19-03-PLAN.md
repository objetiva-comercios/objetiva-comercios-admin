<objective>
Add global field visibility configuration for articulos. Users can toggle which fields appear across forms, list columns, and detail sheet via a settings page.

Purpose: Different businesses use different subsets of article fields. This lets them declutter the UI.
Output: Settings page at /settings/articulos with toggle groups, hook for consuming config, all article UI components respect config.
</objective>

<tasks>
4 chunks, 12 tasks total — see docs/superpowers/plans/2026-03-11-articulos-config.md for full plan.

Chunk 1: Backend (schema, types, DTO)
Chunk 2: Frontend (types, API client, hook)
Chunk 3: Settings page
Chunk 4: Consume config in article components (form, sheet, columns, client)
</tasks>

<success_criteria>

- Settings page at /settings/articulos with 4 toggle groups (13 campos)
- Toggling a field OFF hides it from form, sheet, columns, and list
- Toggling it back ON restores it with data intact
- Config persisted as JSONB in business_settings table
- Campos siempre visibles: codigo, nombre, precioVenta, estado, activo
- Default: talle/color/material OFF, rest ON
  </success_criteria>
