1. **Create `imagen-lightbox.tsx`**:
   - Props interface:
     ```typescript
     interface ImagenLightboxProps {
       images: string[]      // detail URLs (non-null only, already filtered)
       initialIndex: number  // which image to show first
       open: boolean
       onOpenChange: (open: boolean) => void
     }
     ```
   - Uses `Dialog` + `DialogContent` from `@/components/ui/dialog`. Include a visually-hidden `DialogTitle` for accessibility (Radix requires it).
   - State: `current` (number) initialized to `initialIndex` via useEffect when `open` changes to true.
   - **Keyboard navigation** via useEffect:
     - ArrowLeft: `setCurrent(prev => Math.max(0, prev - 1))`
     - ArrowRight: `setCurrent(prev => Math.min(images.length - 1, prev + 1))`
     - Escape handled by Radix Dialog natively.
     - Only bind when `open === true`, cleanup on close.
   - **Layout:**
     - `DialogContent` with `max-w-4xl w-full p-0 bg-black/95 border-none` — dark overlay for photo viewing.
     - Main image: `<img src={API_BASE_URL + images[current]} className="max-h-[80vh] w-auto mx-auto object-contain" alt="" />`
     - Left arrow button: absolute left, `ChevronLeft` icon, disabled when `current === 0`, semi-transparent white on hover.
     - Right arrow button: absolute right, `ChevronRight` icon, disabled when `current === images.length - 1`.
     - Position indicator: bottom center, `text-white/80 text-sm` showing `{current + 1} / {images.length}`.
   - **Navigation is separated by type** (per user decision): the `images` array passed to the lightbox should only contain images of the same type. The parent component is responsible for filtering.

2. **Wire lightbox to edit page** (`editar/page.tsx`):
   - Add state: `const [lightbox, setLightbox] = useState<{ images: string[], initialIndex: number } | null>(null)`
   - Create helper function to open lightbox for a given type:
     ```typescript
     function openLightbox(tipo: 'etiqueta' | 'producto', slotIndex: number) {
       const urls = tipo === 'producto' ? articulo.imagenesProducto : articulo.imagenesEtiqueta
       const nonNullUrls = urls.filter((u): u is string => u != null)
       // Find the position of this slot's URL among non-null URLs
       const url = urls[slotIndex]
       if (!url) return
       const indexInFiltered = nonNullUrls.indexOf(url)
       setLightbox({ images: nonNullUrls, initialIndex: Math.max(0, indexInFiltered) })
     }
     ```
   - Update `ImagenSlotGrid` `onPreview` prop to call `openLightbox(tipo, index)`.
   - Render `<ImagenLightbox>` at the bottom of the component, before the AlertDialog:
     `tsx
     <ImagenLightbox
       images={lightbox?.images ?? []}
       initialIndex={lightbox?.initialIndex ?? 0}
       open={lightbox !== null}
       onOpenChange={(open) => { if (!open) setLightbox(null) }}
     />
     `
     </action>
