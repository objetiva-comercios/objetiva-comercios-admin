       - webhookDeliveries: id (serial PK), webhookId (FK to webhooks.id with cascade), deliveryId (varchar 36 UUID), eventName (varchar 50), payload (jsonb), attempt (integer), success (boolean), httpStatus (integer nullable), responseBody (text nullable), isTest (boolean default false), createdAt

       - `findAll()`: SELECT where revokedAt IS NULL, ordered by createdAt desc. Do NOT return the `secret` field — omit it from the select columns
       - `findOne(id)`: SELECT by id where revokedAt IS NULL (include secret for internal use)
       - `update(id, dto)`: PATCH name/url/events
       - `toggle(id)`: flip active boolean
       - `revoke(id)`: set revokedAt = now()

       - `ping(id)`: send test ping per RESEARCH.md ping implementation, record delivery with isTest=true
       - `findDeliveries(id, page, limit)`: paginated deliveries for webhook, newest first. Return { data, meta: { total, page, limit, totalPages } }
       - `resendDelivery(webhookId, deliveryId)`: find original delivery, re-dispatch with same payload, new deliveryId
       - `dispatchEvent(eventName, payload)`: fetch active non-revoked webhooks, filter by event in-memory, fire-and-forget deliverWithRetry per each
       - `deliverWithRetry(...)`: per RESEARCH.md Pattern 4 — fetch with 10s AbortController timeout, HMAC sign with createHmac('sha256', secret), headers X-Webhook-Signature/X-Webhook-Event/X-Webhook-Delivery, record attempt, retry with setTimeout(10s, 60s)
       - Add Logger instance for error logging

    5. WebhooksController: per RESEARCH.md — GET /, GET /:id, POST /, PATCH /:id, PATCH /:id/toggle, DELETE /:id, POST /:id/regenerate-secret, POST /:id/ping, GET /:id/deliveries (with page/limit query), POST /:id/deliveries/:deliveryId/resend. All @UseGuards(RolesGuard) @Roles('admin')
