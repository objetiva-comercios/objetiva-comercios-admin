| Property | Value |

**Tabler aesthetic overlay** (project-wide rule from CLAUDE.md):
- `border-radius`: use `rounded-md` (6px) for dialogs/cards, `rounded-sm` (4px) for badges/inputs
- Heights: form controls at `h-9` (36px), compact action buttons at `h-8` (32px)
- Shadows: use `shadow-xs` only for cards; dialogs use `shadow-sm`
- Padding/gaps: `py-4` (16px) section padding, `gap-4` (16px) intra-form spacing, `gap-3` (12px) action bars
- Text base: `text-sm` (14px) for all table cells, form labels, body copy

Columns for all 6 tabs (identical schema across all props):

| # | Header | Key | Width | Notes |
|---|--------|-----|-------|-------|
| 1 | ID | `id` | 60px | `font-mono text-sm text-muted-foreground` |

Row hover: `hover:bg-muted/50` (matching existing table patterns).

Inactive rows: `text-muted-foreground` on all cells (visual dim without hiding) when `activo=false`. Only visible when "Mostrar inactivos" toggle is ON.

## PropiedadCreateDialog / PropiedadEditDialog — Form Contract

Dialog size: `sm:max-w-md` (matching deposito-dialog.tsx).

Form fields:

| Field | Type | Placeholder | Validation hint |
|-------|------|-------------|-----------------|
| Nombre | `Input` | "Ej: Shimano" | Required, max 255 |
| Abrev | `Input` | "Ej: SHI" (auto-filled) | Required, `[A-Z0-9]{1,8}` |

**Abrev auto-suggest behavior:**
- When user types into `nombre`, `abrev` field is auto-populated with first 3-4 uppercase ASCII chars (NFD strip + toUpperCase + take first 4 non-diacritic chars)
- Auto-suggest updates live while `abrev` has not been manually edited
- Once user edits `abrev` field directly, auto-suggest stops (manual lock — track with `abrevManuallyEdited` local state flag)
- `abrev` field shows a small inline hint: `text-xs text-muted-foreground` — "1-8 caracteres, solo mayúsculas y dígitos"

Dialog title:
- Create: "Nueva [propNombre singular]" (e.g. "Nueva Marca")
- Edit: "Editar [propNombre singular]"

Footer buttons:
- Cancel: `variant="outline" size="sm"` — "Cancelar"
- Submit: `size="sm"` — "Crear [propNombre singular]" / "Guardar cambios"
- Submit loading state: `Loader2 mr-2 h-4 w-4 animate-spin` inline before text

Form spacing: `space-y-4` (matching deposito-dialog.tsx).

## PropiedadDeactivateDialog — Soft-Delete Confirmation

Uses `AlertDialog` (not `Dialog`):

- Title: "Desactivar [nombre del valor]"
- Body: "Vas a desactivar '[nombre]'. Los artículos existentes que la usan no se modifican. ¿Confirmás?"
- Cancel: "Cancelar" (default)
- Confirm: "Desactivar" (`variant="destructive" size="sm"`)

Reactivation does NOT require confirmation — it's a direct flip via DropdownMenuItem "Reactivar" with inline `Loader2` on the row action.

## Interaction States

| State | Behavior |
|-------|----------|
| Tab initial load | `Skeleton` rows — 5 rows × 4 cols, `h-8` each |
| Tab switching | Skeleton shown on first load only; subsequent tab revisits use cached data |
| Row action loading | Disable the `MoreHorizontal` button on the affected row, show `Loader2 h-3.5 w-3.5` in its place |
| Form submit loading | Disable all form inputs + cancel button, show `Loader2` in submit button |
| "Mostrar inactivos" toggle | Re-fetch with `activo=all` query param; table re-renders immediately with stale-while-revalidate |
| abrev auto-suggest | Debounce 150ms on `nombre` onChange — prevents jitter while typing |
| Unique constraint error (nombre) | Inline `FormMessage` below `nombre` field: "El nombre ya existe en [propNombre plural]" |
| Unique constraint error (abrev) | Inline `FormMessage` below `abrev` field: "La abreviación ya existe en [propNombre plural]" |
| abrev format error | Inline `FormMessage`: "La abreviación debe tener 1 a 8 caracteres en mayúsculas o dígitos" |

## PropiedadCreateDialog Standalone (for Phase 32 reuse)

`PropiedadCreateDialog` is delivered as a standalone reusable component in this phase. Its visual contract is identical to the create variant of the form above.

Additional prop signature (for Phase 32 consumption):
- `propTipo: 'marca' | 'color' | 'talle' | 'material' | 'presentacion' | 'objeto'` — drives title + copy
- `onCreated: (newValue: { id: number; nombre: string; abrev: string }) => void` — called on success so the parent `AtributoSelectField` can immediately append + select the new value
- `trigger?: ReactNode` — optional custom trigger (Phase 32 will pass a "+" button inline in the combobox)

When rendered standalone (Phase 29 testing), it can be triggered from a page-level "Nueva propiedad" button.
