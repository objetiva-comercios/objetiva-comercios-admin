## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Filesystem → PostgreSQL prod | DDL crítico cruza el límite — migration aplica DROP COLUMN sobre prod con ~101.021 filas |
| Drizzle queries → DB | Runtime queries dependen de que schema.ts y DB estén alineados (lección 2026-05-15) |
