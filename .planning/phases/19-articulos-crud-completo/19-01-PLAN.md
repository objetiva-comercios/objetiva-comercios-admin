```typescript
export function getColumns(handlers: {
  onEdit: (articulo: Articulo) => void
  onToggle: (articulo: Articulo) => void
}): ColumnDef<Articulo>[]
```

2. Keep all existing column definitions inside the function return.

3. Add a new `actions` column at the END of the array with `id: 'actions'`, `enableHiding: false`:
   - Cell renders a `RowActions` component (define in same file).
   - `RowActions` renders a `DropdownMenu` with `DropdownMenuTrigger` (ghost Button with `MoreHorizontal` icon, h-8 w-8 p-0).
   - CRITICAL: `onClick={(e) => e.stopPropagation()}` on the trigger Button AND on each `DropdownMenuItem` to prevent opening the sheet.
   - Two items: "Editar" (with PencilIcon, calls `handlers.onEdit`) and a contextual label (`articulo.activo ? 'Desactivar' : 'Reactivar'`, calls `handlers.onToggle`).
   - Import: `MoreHorizontal`, `PencilIcon` from lucide-react; `DropdownMenu`, `DropdownMenuContent`, `DropdownMenuItem`, `DropdownMenuTrigger` from `@/components/ui/dropdown-menu`; `Button` from `@/components/ui/button`.

4. Keep `defaultColumnVisibility` export unchanged.

**articulos-client.tsx:**

1. Replace `import { columns }` with `import { getColumns }` from the columns file.

2. Add state: `const [toggleTarget, setToggleTarget] = useState<Articulo | null>(null)`

3. Add `useRouter()` import from `next/navigation`.

4. Create `handleEdit` callback: `router.push(\`/articulos/\${encodeURIComponent(articulo.codigo)}/editar\`)`.

5. Create `handleToggleRequest` callback: sets `setToggleTarget(articulo)`.

6. Memoize columns: `const tableColumns = useMemo(() => getColumns({ onEdit: handleEdit, onToggle: handleToggleRequest }), [handleEdit, handleToggleRequest])`.

7. Create `handleConfirmToggle` async function:
   - Save `const target = toggleTarget; setToggleTarget(null)` immediately (close dialog).
   - Optimistic update: if `statusFilter === 'active' && target.activo`, filter out from `data`. If `statusFilter === 'inactive' && !target.activo`, filter out.
   - Save `previousData` before filtering for rollback.
   - Call `toggleArticuloActivo(target.codigo)`.
   - On success: toast with contextual message ("Articulo desactivado"/"Articulo activado").
   - Then `fetchData(page, search, statusFilter)` to refresh totals.
   - On error: `setData(previousData)`, destructive toast.

8. Update search Input placeholder to `"Buscar articulos..."` (per user decision).

9. Pass `tableColumns` to `ServerDataTable` instead of `columns`.

10. Add `AlertDialog` OUTSIDE the table, controlled by `toggleTarget`:

```tsx
<AlertDialog open={!!toggleTarget} onOpenChange={open => !open && setToggleTarget(null)}>
  <AlertDialogContent>
    <AlertDialogHeader>
      <AlertDialogTitle>
        {toggleTarget?.activo ? '¿Desactivar articulo?' : '¿Reactivar articulo?'}
      </AlertDialogTitle>
      <AlertDialogDescription>
        {toggleTarget?.activo
          ? `"${toggleTarget.nombre}" no aparecera en la lista principal.`
          : `"${toggleTarget?.nombre}" volvera a aparecer en la lista.`}
      </AlertDialogDescription>
    </AlertDialogHeader>
    <AlertDialogFooter>
      <AlertDialogCancel>Cancelar</AlertDialogCancel>
      <AlertDialogAction onClick={handleConfirmToggle}>
        {toggleTarget?.activo ? 'Desactivar' : 'Reactivar'}
      </AlertDialogAction>
    </AlertDialogFooter>
  </AlertDialogContent>
</AlertDialog>
```

Import AlertDialog components from `@/components/ui/alert-dialog`. Import `toggleArticuloActivo` from `@/lib/api.client`. Import `useToast` from `@/hooks/use-toast`. Import `useMemo` from react. Import `useRouter` from `next/navigation`.
